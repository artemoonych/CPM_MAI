# CPM_MAI

## О проекте
Программа выполняет расчет критического пути (CPM) для проекта цифровизации образовательного учреждения. Позволяет определить критические работы, резервы времени, построить сетевой график и диаграмму Ганта.

## Структура проекта
- `cpm.py` - основной скрипт Python.
- `activities.json` - входные данные проекта.
- `network_graph.png` - визуализация сетевого графа.
- `gantt_chart.png` - диаграмма Ганта.
- `requirements.txt` - зависимости Python.
